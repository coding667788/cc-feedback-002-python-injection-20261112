请从零开发一个离线 Python 注入漏洞扫描器，判断外部输入能否跨模块进入危险 SQL 或系统命令，并给出传播路径。使用 Windows 原生 Python 3.12，可用 ast 和 SQLite；只解析源码，不执行样例，不使用现成扫描引擎或大模型接口。

1. 以 FastAPI 风格路由参数为来源，支持至少三层直接函数调用、相对导入与别名、简单 if 分支及固定对象/字典字段。同一函数的安全调用与受污染调用要分开，不能把一个字段的污点扩散到全部字段。
2. 检出 sqlite3 查询字符串拼接和 shell=True 命令拼接；固定 SQL 加绑定参数、固定原生程序的 shell=False 参数列表不误报。int 转换成功后转成的十进制字符串可视为安全，异常分支使用原字符串仍要报警。
3. 输出 JSON 报告，标明来源、危险参数、文件行号、调用与分支证据。互斥分支不能拼成漏洞路径；超出支持范围要明确报告，不能当成零漏洞。
4. 持久化缓存支持重复扫描。修改或删除公共函数后，相关调用者重新分析，无关模块可复用；增量结果须与干净全量结果一致，缓存写入中断后重启也如此。

自建正反例，验证跨模块传播、调用和字段隔离、互斥分支、净化失败分支、缓存失效及中断恢复，断言具体报告内容。交付扫描命令、样例、自动化测试和 Windows 运行说明，写清实测结果及未完成项。没有外部附件，不使用 Docker。
